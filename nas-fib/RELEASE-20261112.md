# 2026-11-12 地区自动选择

## 问题与实现

地区策略原来硬编码 fallback，慢但仍可用的节点不会因其他节点更快而自动切换。
地区定义增加可选 type 和 tolerance；旧定义仍默认 fallback，url-test 默认容差 300 ms。
限制 type 为 fallback/url-test，容差为 0–65535 整数，拒绝无效配置。
示例策略的八个地区组切换为 url-test / 300 ms。保留名称、成员筛选、60 秒周期、lazy=false；
日本链式代理保持原先 fallback。保留组名是为避免破坏已保存的策略选择和引用。
